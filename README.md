# Veyra

Veyra is a modular social profile discovery, validation, scoring, and snapshot intelligence engine.

> Veyra is currently under active development.

## Status

Early development — foundation phase.

## Architecture

Veyra is being designed around:

- Clean Architecture
- modular domain boundaries
- explicit dependency direction
- repository abstractions
- configurable validation rules
- configurable scoring rules
- reproducible profile snapshots
- local media persistence
- structured logging
- strong typing
- automated testing

## Python

Veyra requires Python 3.13 or newer.
